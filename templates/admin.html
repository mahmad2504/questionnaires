Add a questionnaire

Create a folder using letters, numbers, and hyphens. Put config.json and instructions.md inside it. A questionnaire is on unless config.json contains "enabled": false. Set start to the date it should appear on the people portal, YYYY-MM-DD or YYYY-MM-DDTHH:MM. Omit it to show the questionnaire under Active as soon as it is turned on. A future start keeps it under Planned, with the time it becomes active, until then. It stays visible until you turn it off. Turned-off questionnaires are listed on the Archive page. Set label to the short name shown next to the logo, such as Status update, Survey, Feedback, or Acknowledgement. Omit it to show Responses. Open Respondents on a questionnaire to choose who should reply. The list is stored encrypted in respondents.txt. While that list exists, only those addresses can see the questionnaire.
