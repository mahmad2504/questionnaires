Add a questionnaire

Create a folder using letters, numbers, and hyphens. Put config.json and instructions.md inside it. A questionnaire is on unless config.json contains "enabled": false. Add respondents.txt with one email per line for the replied / waiting list. While the questionnaire is open, only those addresses can see it.
